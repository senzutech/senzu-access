# Security policy

This tool creates an administrative account on customers' servers, so reports are taken
seriously and handled first.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/senzutech/senzu-access/security/advisories/new)
or write to security@senzu.tech. We acknowledge within two working days and aim to ship a fix
within seven.

## Scope

In scope: anything that lets the access open when it should be closed, lets the agent user gain
rights it should not have, or leaves something behind after `--uninstall`.

## Supported versions

Only the latest release receives security fixes.
